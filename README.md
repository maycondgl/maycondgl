## 🚀 Projeto em Destaque (Flagship)

### 💈 BarberShop — Plataforma SaaS de Barbearias em Tempo Real

Aplicação completa de gestão e agendamentos desenvolvida com **.NET 10**, **Blazor WebAssembly**, **MudBlazor**, **Minimal APIs** e **SignalR**.

- 🌐 **Aplicação no Ar (Azure)**: [https://barbershop-web-gwbhheaaf0cfewgm.centralus-01.azurewebsites.net](https://barbershop-web-gwbhheaaf0cfewgm.centralus-01.azurewebsites.net)
- 📌 **Repositório Vitrine**: [Visitar BarberShop Showcase](https://github.com/maycondgl/barbershop-showcase)
- **Destaques**:
  - Agendamentos inteligentes com prevenção de conflitos de horários em tempo real.
  - Sincronização instantânea com SignalR entre clientes e profissionais.
  - Clube de assinaturas com planos recorrentes e integração de pagamentos Pix.
  - Mais de 240 testes unitários automatizados garantindo integridade das regras de negócio.

## 🛠️ Stacks & Tecnologias

- **Backend**: C#, .NET 8 / 10, ASP.NET Core (Minimal APIs), Entity Framework Core, SignalR Core, Identity.
- **Frontend**: Blazor WebAssembly, MudBlazor, PWA (Progressive Web Apps), HTML5, CSS3 / Modern CSS.
- **Banco de Dados**: SQL Server, Modelagem Relacional, Migrations, Otimização de Consultas (NoTracking, Índices).
- **Testes & Qualidade**: xUnit, FluentAssertions, Testes Unitários e de Integração.
- **DevOps & Cloud**: Microsoft Azure (App Services), Git, GitHub.
